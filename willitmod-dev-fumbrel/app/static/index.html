What gets touched?

App recipes are backed up before changes. Your installation IDs, wallets, chain data and payout settings stay in place. Starting an updated app can run its normal data migrations.

What won’t this cure?

Unknown failures, damaged data and CPU “illegal instruction” crashes need their own diagnosis. No magic umbrella for those.
